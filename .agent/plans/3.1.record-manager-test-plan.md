# Test plan: Module 3 – Record Manager

Scope: `.agent/plans/3.record-manager.md`. Run against the real stack (Supabase + local Ollama + FastAPI + Vite) with the Playwright MCP, plus API calls made from the browser session and a LangSmith query.

Every test states **why** it exists. Test data: two throwaway users (`rlstest-a3`, `rlstest-b3`) and generated text files with unique marker words so retrieval can prove old content is gone and new content is searchable.

| ID | Scenario | Pass criteria | Why |
|---|---|---|---|
| A1 | Upload `notes.md` (new) | action `created`; status goes pending → processing → completed via Realtime; `chunk_count` > 1; stored `content_hash` equals the SHA-256 computed independently in Node/Python | Baseline, and proves the server-recorded hash is the real hash of the bytes |

| A6 | Revert to the original A1 bytes | Action `updated` (stored hash is the edited one), not `unchanged` | Hash comparison is against the current version, not history |

### Bug found: stale storage read after an in-place overwrite
Overwriting the storage object and re-ingesting within about a minute of the previous download made the backend read the **previous bytes** (CDN cache). The hash check caught it and failed the document ("does not match its recorded hash"), so nothing stale was indexed, but a quick edit-and-re-upload would fail. Re-running the same ingestion 82 s later succeeded, which confirmed the cause.
**Fix:** `storage.download(..., version=content_hash)` adds `?v=<hash>` and `Cache-Control: no-cache`; ingestion passes the document's hash. Verified: three versions of one file uploaded about 3 s apart all completed with only their own content.

### Other observations (not changed)
- Deleting a document whose file was never uploaded returns 502 and leaves the row: `services/storage.delete` only treats 404 as "missing", but Supabase returns 400 for a missing object (Module 2 code, not Module 3).
- `run_ingestion` never raises, so LangSmith shows `success` even for failed ingestions.
- Running pytest sends `ingest_document` traces with `document_id=d1` to the real LangSmith project.
